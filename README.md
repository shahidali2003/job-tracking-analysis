# Job Tracking Analytics System

## Problem
Manual job tracking scattered tha → insights nahi mil rahe the

## Solution
- PostgreSQL database design (jobs + activities)
- SQL queries for analytics (conversion, activity tracking)
- Power BI dashboard for visualization

## Key Insights
- Application to offer conversion rate
- Location-wise job distribution
- Activity tracking timeline

## Tech Stack
PostgreSQL | SQL | Power BI

## Features
- KPI tracking (jobs, interviews, offers)
- Funnel analysis
- Interactive filters (location, priority, status)
